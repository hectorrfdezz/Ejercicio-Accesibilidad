# Proyecto Accesibilidad

Ejercicio de desarrollo web centrado en la creación de una página para un gimnasio, utilizando **HTML, CSS y JavaScript**. El proyecto incorpora mejoras de accesibilidad, navegación y validación de formularios.

### Características principales

- **Diseño responsive:** adaptación de las tarjetas de planes a pantallas más pequeñas.
- **Accesibilidad:** navegación mediante teclado, indicadores de foco visibles y etiquetas semánticas.
- **Planes de gimnasio:** presentación de diferentes opciones con botones interactivos.
- **Formulario de contacto:** validación de campos y mensajes de error.
- **Modal de registro:** apertura y cierre mediante botones, tecla Escape y gestión del foco.
- **Contraste visual:** combinación de colores para facilitar la lectura.

### Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript

### Objetivo

Practicar el desarrollo frontend aplicando buenas prácticas de estructura, interacción y accesibilidad web.

**Nota:** Es una demostración funcional de interfaz. Las acciones de compra, registro y envío de mensajes son simuladas y no están conectadas a un servidor.
